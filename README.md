# SEONGHYEON V2 — Laskar Cinta Inspired

Website fan-made/tribute untuk Seonghyeon dari CORTIS dengan visual cinematic dark-luxury, maroon/gold, editorial typography, film grain, cursor glow, constellation, gallery, letter, music player, dan mini game.

## Upload ke GitHub Pages

1. Buat repository baru.
2. Upload `index.html`, `style.css`, `script.js`, dan folder `assets`.
3. Pastikan `index.html` berada di root.
4. **Settings → Pages → Deploy from a branch → main → /(root) → Save.**

## Memasang lagu

Website sudah memiliki music player. Jika kamu memiliki file audio yang memang boleh kamu gunakan, letakkan:

`assets/laskar-cinta.mp3`

Tidak ada file lagu berhak cipta yang disertakan dalam ZIP ini.

## Memasang foto

Buat folder:

`assets/photos/`

Kemudian simpan foto di sana. Placeholder gallery di `index.html`/`style.css` dapat diganti dengan background atau `<img>` milikmu.

## Catatan

Website ini fan-made dan tidak berafiliasi secara resmi dengan CORTIS atau Dewa 19. Visualnya mengambil inspirasi atmosfer rock/filosofis yang kamu minta, bukan menyalin artwork resmi.
