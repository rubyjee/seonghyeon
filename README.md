# SEONGHYEON — The Sacred Archive

Website tribute/fan-made untuk Seonghyeon dari CORTIS.

## Isi
- Cinematic opening
- About / archive
- Gallery placeholder interaktif
- Music section
- Letter
- Interactive star field
- Mini game "Catch the Light"
- Responsive mobile design

## GitHub Pages

1. Buat repository baru di GitHub.
2. Upload semua file dalam folder ini.
3. Pastikan `index.html` berada di root repository.
4. Buka **Settings → Pages**.
5. Pilih **Deploy from a branch**.
6. Branch: `main`, folder: `/ (root)`.
7. Save.

## Mengganti foto
Versi awal menggunakan placeholder agar ZIP tetap ringan. Kamu dapat mengganti elemen `.photo-placeholder` di `index.html` dengan `<img src="assets/foto.jpg">`, lalu buat folder `assets` dan upload foto kamu.

## Catatan musik
Jangan mengunggah file musik berhak cipta ke repository tanpa izin. Gunakan link/embed dari sumber resmi.
